VIGOROUS PROPERTY — ASTRO STARTER (HOME PAGE V1)

This ZIP is a DROP-IN starter for your existing Astro v7 project.
It does NOT include package.json and it will NOT overwrite your installed dependencies.

INSTALL:
1. Stop your running dev server: Ctrl+C in terminal.
2. Unzip this package.
3. Copy its 'src' folder and 'public' folder into:
   C:\Users\Admin\Downloads\VigorousProperty\vigorous-property\
   Allow Windows to replace the default src/pages/index.astro.
4. Open that folder in VS Code.
5. Run: npm run dev
6. Visit: http://localhost:4321/
